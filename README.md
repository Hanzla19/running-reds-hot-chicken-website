# Running Red's Hot Chicken Website 🌶️🍗

A modern, bold, and highly animated restaurant website designed for **Running Red's Hot Chicken** in Lincoln, Nebraska.

## 🚀 Project Overview

The goal of this project was to create more than a basic restaurant website. The website combines:

- Restaurant branding
- Online menu
- Food ordering experience
- Payment-ready checkout flow
- Heat-level presentation
- Restaurant information
- Catering and events
- Customer rewards
- Local SEO
- Analytics and marketing tracking

The design is inspired by the energy of modern hot chicken brands while maintaining a unique visual identity for Running Red's.

## 🎨 Design Direction

The website uses a bold visual style based around:

- Red
- Black
- White
- Yellow accents
- Street-art influence
- Sports energy
- Youthful typography
- Food-focused photography
- Smooth animations and transitions
- Running Red mascot
